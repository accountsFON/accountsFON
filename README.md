## Open Source Tools

- **[Lid Awake](https://github.com/accountsFON/lid-awake):** close your MacBook and keep working. A menu bar app that keeps your Mac running with the lid shut, locks it on close, and supports AI computer use.
- **[Heads Up](https://github.com/accountsFON/heads-up):** Mac notifications for Claude Code that only fire when Claude needs you, and open the waiting session on click.
- **[Second Brain System](https://github.com/accountsFON/second-brain-system):** a shared second brain for your whole team and every AI tool, built from plain markdown files.
- **[Profit First Calculator](https://accountsfon.github.io/profit-first-calculator/):** a starter calculator that recommends Profit First allocations for new businesses.
